# 云数中台 · 核心业务流程（Mermaid）

> **依据**：SRS V1.2、落地 PRD v1.2、当前 `mt-web` / `v8-web` 功能模块  
> **日期**：2026-09-08  
> **说明**：以下为产品级业务流；推送接收为系统能力（无独立运营配置页，或挂在数据推送管理预留区）。

## 模块对照（当前实现）

| 端 | 模块 | 在主链路中的作用 |
| --- | --- | --- |
| MT | 供数方管理 | 主数据 + appkey，接口路径识别厂商 |
| MT | 机构供数配置 | 机构可接收供数方；可绑定生效标准 |
| MT | 字段库管理（全部字段 / 快速模板） | 标准字段素材；模板供方案第 2 步选用 |
| MT | 接入方案管理（三步：基础信息 → 字段库配置 → 接入方式） | 拼装「数据标准 + 接入策略」并发布 |
| MT | IP 白名单 | 方案开启白名单时强制校验来源 IP |
| MT | 数据推送管理 | 使用方 / 外推（本期预留深化） |
| V8 | 接入规范 | 预览/下载本机构生效标准 |
| V8 | 数据概览 / 供数统计 / 供数方查看 | 核验入库量与已配置关系（保持既有） |

## 1. 端到端主链路（总览）

运营定标准与关系 → 机构下载规范转交供方 → 供方按路径推数 → 中台校验落库打标 → 机构看量。

同内容备份：[`yunshu-e2e-main-flow.xml`](./images/src/yunshu-e2e-main-flow.xml)

  D5 -->|未命中| D8

## 2. 运营配置准备流（模块串联）

先有字段与模板，再拼方案；供数方与白名单并行准备；最后给机构配关系。

```mermaid
flowchart LR
  F[字段库·全部字段<br/>维护启用字段] --> T[字段库·快速模板<br/>系统内置/用户自定义]
  T --> S[接入方案·第2步<br/>选用模板或勾选字段]
  F --> S
  B[基础信息<br/>名称/范围全局或机构/状态] --> S
  S --> M[接入方式<br/>接口或库表/频次/白名单开关]
  M --> P[发布启用方案]
  SUP[供数方管理<br/>appkey] --> ORG[机构供数配置]
  WL[IP 白名单] -.->|被方案引用| M
  P --> ORG
  ORG --> DONE[机构可下载生效标准]
```

## 3. 接入方案拼装（三步向导）

对应 MT「接入方案管理 → 新增/编辑」。

```mermaid
flowchart TD
  START([新增 / 编辑接入方案]) --> STEP1[第1步 基础信息<br/>方案名称、范围全局/机构、<br/>机构、状态开启/停用]
  STEP1 --> STEP2[第2步 字段库配置]
  STEP2 --> TPL{点选快速模板?}
  TPL -->|是| APPLY[按模板勾选字段集]
  TPL -->|否| MANUAL[手工勾选字段]
  APPLY --> EDIT[可再增删字段]
  MANUAL --> EDIT
  EDIT --> SAVE_TPL{已选字段非空且<br/>与已有模板字段集不同?}
  SAVE_TPL -->|是| CUSTOM[可「保存为模板」<br/>类型=用户自定义]
  SAVE_TPL -->|否| HIDE[不展示保存按钮]
  CUSTOM --> STEP3
  HIDE --> STEP3[第3步 接入方式<br/>数据源类型、频次、<br/>是否 IP 白名单、请求示例等]
  STEP3 --> CHK{库表类型?}
  CHK -->|是| REQ{含 supplier_code<br/>与 org_id?}
  REQ -->|否| FAIL[提交失败提示补全]
  REQ -->|是| PUB[提交发布]
  CHK -->|接口| PUB
  PUB --> ENABLE{启用规则}
  ENABLE -->|全局| G1[全局同时仅 1 条启用]
  ENABLE -->|机构| G2[同机构至多 1 条启用]
```

## 4. 生效标准判定（机构下载 / 推送校验共用）

```mermaid
flowchart TD
  Q([求本机构生效标准]) --> C1{机构供数配置<br/>是否绑定启用标准?}
  C1 -->|是| R1[使用绑定标准]
  C1 -->|否| C2{是否存在该机构<br/>启用中的机构方案?}
  C2 -->|是| R2[使用机构方案]
  C2 -->|否| C3{是否存在启用中的<br/>全局方案?}
  C3 -->|是| R3[使用全局方案]
  C3 -->|否| R4[无生效标准<br/>无法下载/无法按标准接入]
  R1 --> OUT[生效标准 =<br/>字段块 + 接入方式说明]
  R2 --> OUT
  R3 --> OUT
```

## 5. 供数推送接收与落库（双路径）

```mermaid
flowchart TD
  IN([供数方送数到达]) --> PATH{接入方式}
  PATH -->|接口 API| API[校验 appkey<br/>对应供数方须启用]
  PATH -->|库表 / JDBC| JDBC[读取行内 supplier_code<br/>匹配供数方编码]
  API -->|失败| REJ[拒收 · 不落库]
  JDBC -->|无法识别| REJ
  API -->|通过| IP
  JDBC -->|通过| IP
  IP{生效方案开启<br/>IP 白名单?}
  IP -->|是且 IP 未登记| REJ
  IP -->|否或 IP 命中| ORG[解析归属机构 org_id]
  ORG -->|无法归属| REJ
  ORG -->|可归属| REL{该机构供数配置<br/>是否包含此供数方?}
  REL -->|否| KEEP[原文可存但不计入<br/>该机构新入库量]
  REL -->|是| OK[落库副本<br/>打标：厂商 / 时间 / 机构]
  OK --> STAT[计入 V8 概览与供数统计]
```

## 6. 机构侧使用流（V8）

```mermaid
flowchart LR
  L[机构管理员登录] --> O[数据概览<br/>供数方数 / 总条数 / 最近入库]
  O --> ST[供数统计<br/>按供数方核条数]
  O --> SP[供数方查看<br/>只读已配置名单]
  O --> SPEC[接入规范]
  SPEC --> DL[预览 / 下载生效标准]
  DL --> HAND[转交供数方按标准推送]
```

## 8. 快速模板生命周期

```mermaid
flowchart LR
  SYS[系统内置模板<br/>不可删改字段集] --> PICK[方案第2步点选套用]
  NEW1[字段库·快速模板<br/>「新增模板」勾选字段] --> CUSTOM[用户自定义模板]
  NEW2[方案第2步<br/>「保存为模板」] --> CUSTOM
  CUSTOM --> PICK
  CUSTOM --> EDIT[模板 Tab 编辑名称/说明/字段]
  CUSTOM --> DEL[可删除]
  PICK --> SCHEME[写入当前方案字段勾选]
```

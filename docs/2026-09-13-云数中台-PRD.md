## 第一部分 · 概念对齐

> 云数中台是给**平台运营**和**机构管理员**用的 **PC Web 多租户汇聚入口**：供数按标准接入并落库打标；运营将机构已入库数据按**推送方案**主动回推至接收端（HTTP 或消息队列）。  
> **不做（本期）**：跨机构外推；文件通道正式开放；真实调度与对端生产联调（原型 Mock）；看板环比同比、延迟 SLO、告警引擎。

## 第二部分 · 落地需求（增量）

### 5.2 接入方案管理（相对 v1.3/v1.5 修订）

- 列表「接入方式」筛选项：仅 **HTTP/HTTPS POST 推送**、**消息队列订阅**（无文件传输类）。  
- 操作列：详情、预览文档、编辑、**复制**、删除；状态可列表启停。  
- 「机构」列：主名称 + 副文案「所属统计单元·所属销售」。  
- 详情页：无「编辑」、无顶部统计卡；模块顺序：基础信息 → 字段库配置 → 接入方式。

### 5.2.x 接入数据明细（修订）

- 筛选：方案、时间范围。  
- **时间默认不填**，列表按历史全量；从综合看板等入口携带时间参数时才预填。  
- 「机构」列含副信息。

### 5.7 数据推送管理（相对 v1.4/v1.5 重写）

一级菜单「数据推送管理」下三个二级页：

1. **推送方案管理**  
2. **推送数据明细**  
3. **接收方管理**（第三方接收方机构）

> **模型说明**：推送方案绑定接收方（MT 机构或第三方接收方），自含通道/策略/启停与方案级 stats；**不再**要求单独的「机构推送任务」列表作为主运行单元。

#### 5.7.1 推送方案

**列表 KPI**：方案总数（启用/停用 chip，点击筛状态；点总数清状态）、机构数量、累计成功推送、推送成功率（成功/(成功+失败)；无流量为「—」）。

**筛选**：方案、机构、通道类型、推送模式、状态（**无供数方**）。

**列**：方案名称、机构（含副信息）、数据范围、通道、模式、成功量、失败量、状态、操作。  
**不展示**：频次、最近推送。

**交互**

- 方案名称 / 机构 / 通道 / 模式 / 状态：点击回填筛选并刷新。  
- 成功量 → `/push/push-data?schemeId=&schemeName=&pushResult=success`  
- 失败量 → 同上，`pushResult=fail`  
- 操作：详情、编辑、**复制**、启停。

**配置向导（三步）**

1. 基础信息（名称、接收方类型与机构、状态、备注等）。  
2. 选择推送数据：来源（接入方案/数据源）、预览、过滤、去重。  
   - 预览文案：预览最多展示 100 条样例数据，所选数据来源目前全量范围数据 N 条，可预览查看并设置数据过滤范围。  
   - 数据去重：**默认关闭**。  
3. 推送方式：  
   - **推送类型**仅两项：HTTP/HTTPS POST 推送、消息队列推送。  
   - 说明：中台主动推送的方式，当前支持HTTP接口和消息队列两种方式。  
   - 含协议/鉴权/限流或 MQ 连接项；推送模式、调度、批量上限等。

**详情**：无编辑、无统计卡；基础信息 → 推送数据范围（含过滤条件表）→ 推送方式。

#### 5.7.2 推送数据明细

- 筛选：推送方案、**推送结果**（成功/失败）、时间范围。  
- 列表固定列含：方案名称、机构、供数方、推送时间、**推送结果**，其后为动态业务字段。  
- 时间默认空=全量；带参入口预填。

#### 5.7.3 与综合看板

| 能力 | 归属 |
|------|------|
| 方案配置、启停、方案级成功/失败/积压 | 推送方案管理 |
| 双流总览、值班区、下钻 | 综合看板（v1.5） |
| 明细全量/按结果查询 | 推送数据明细 |

### 6 验收（增量）

- 推送方案列表 KPI、点击回填、成功/失败下钻可用。  
- 推送类型在表单/列表/筛选/详情均为「HTTP/HTTPS POST 推送」「消息队列推送」。  
- 接入与推送明细无默认时间时展示全量；推送明细可见「推送结果」筛选与列。  
- 详情页无编辑按钮、无顶部统计卡。

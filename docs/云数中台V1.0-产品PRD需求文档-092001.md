# 3. 需求概述

### 3.1 需求背景

云数中台面向平台运营与机构侧数据汇聚场景：多家供数厂商按统一标准向中台送数，中台完成校验落库与打标后，再按机构维度将已入库数据**主动推送**回 MT 机构接收端（HTTP 或消息队列）。运营管理团队需要在同一套 PC Web 管理端完成：接入/推送配置、启停管控、明细对账、综合看板与主数据维护，避免配置散落、口径不一、问题难追溯。

本期交付以 **MT 管理端**为核心，机构管理（机构列表/机构授权管理/机构用户管理）与系统设置（数据字典）在 MT 管理端提供本地功能页，满足原型演示与验收闭环；正式环境规划对接 V8 应用集成管理中心标准模块与 MT 统一认证中心。

### 3.2 业务现状与建设必要性

|**维度**|**现状痛点**|**建设必要性**|
|---|---|---|
|接入配置|多供数方、多机构字段口径不一，缺少统一方案与字段库|以「接入方案」固化接入数据的具体字段映射与通道，生成可下发文档|
|安全接入|来源 IP、鉴权缺少统一管控面|方案级白名单开关 \+ 平台级 IP 白名单，拒收不落库|
|推送外发|外发策略与结果散落，难按方案启停与统计|「推送方案即运行单元」，绑定 MT 机构与调度策略|
|数据汇总统计|缺少双流（接入/推送）一屏总览与下钻|综合看板 \+ 明细带参跳转，支撑汇报与排障|

### 3.3 业务需求

1. 提供综合看板：接入/推送概况、趋势对比、分维统计与异常区，支持机构多选与时间跨度筛选，并可下钻明细。

2. 机构管理（机构列表、机构授权管理、机构用户管理）与系统设置（数据字典）为本期 MT 管理端本地功能页。

3. 维护供数方、字段库（含快速模板）、IP 白名单等主数据，支撑接入配置与校验。

4. 配置接入方案（基础信息 / 字段库 / 接入方式三步），支持列表筛选、启停、复制、删除、文档预览与 PDF 下载、详情查看（鉴权 Header 可维护）。

5. 按方案/机构/供数方/时间等查询接入数据明细，默认全量，支持带参预填与字段级筛选。

6. 配置推送方案（基础信息 / 推送数据 / 推送方式三步），支持推送模式筛选、启停、复制、删除、详情只读。

7. 按方案/机构/推送结果/时间等查询推送数据明细，支持成功/失败筛选与下钻。

8. 系统侧按方案完成接入鉴权与白名单等校验，通过后落库打标。

### 3.4 业务目标

|**目标**|**说明**|**度量**|
|---|---|---|
|入出可控|接入拒收可解释；推送启停按方案生效|停用方案后新流量为 0；拒收不落库|
|配置可交付|接入文档可预览/下载给供数方|方案保存后可生成文档|
|管理可概览<br>|一屏看双流 统计/趋势/异常并可下钻|看板筛选后图表与列表联动<br>|
|问题可追溯|接入/推送明细可按方案与结果查询|带参跳转筛选项正确回填|

### 5.2 使用场景

#### 场景一：双流（数据接入/数据推送）统计总览

1. 运营从门户进入 MT，默认落在综合看板模块。

2. 选择机构（可多选）与时间「今日」，点击刷新。

3. 查看接入概况与推送概况 统计数据、趋势图。

4. 在异常区发现「高失败率」方案，点击下钻至推送明细（带方案 \+ 推送结果=失败）。

5. 核对失败样本后，回到推送方案列表检查通道配置或临时停用。

#### 场景二：为新机构开通接入

1. 在供数方管理新增/确认供数方编码，复制给厂商。

2. 在字段库确认字段或套用快速模板；必要时批量新增。

3. 在 IP 白名单为该供数方录入来源 IP 并启用。

4. 新增接入方案：选机构与供数方、开启白名单管控、勾选字段、配置 HTTP/HTTPS POST（消息队列订阅本期停用）。

5. 保存后预览/下载接入文档发给供数方；列表开启方案。

6. 供方送数后，在接入数据明细按方案与时间核对入库。

#### 场景三：配置回推至 MT 机构

1. 在「机构管理」列表确认目标机构已开通且授权状态正常（正式环境由 V8 应用集成管理中心同步）。

2. 新增推送方案：目标仅可选 MT 机构；选择接入方案或数据源作为范围；配置推送字段映射、过滤与（可选）去重。

3. 第三步选择 HTTP/HTTPS POST 推送（消息队列本期停用），配置鉴权 Header 与推送模式（增量/全量）等。

4. 开启方案后，在推送方案列表观察成功量/失败量；点击失败量进明细。

5. 看板推送概况同步反映成功率与积压。

#### 场景四：停用与清理无效方案

1. 列表将接入或推送方案开关切至停用，确认弹窗文案明确「已产生数据不受影响 / 不再推送」。

2. 停用后尝试删除，确认「删除后不可恢复」。

3. 开启态删除按钮置灰并 Tooltip「开启状态的方案不可删除，请先停用」。

4. 字段被方案引用时不可删除；供数方被引用时限制删除。

#### 6.1.4 业务规则

1. 筛选变更后看板内所有区块联动同一筛选条件。

2. 默认时间跨度为「今日」（today）。

3. 下钻 时间跨度必须计算映射到具体起止时间段（3d→d3、1w→w1、1m→m1），不得原样传 3d/1w/1m。

### 6.2 机构管理

本模块为 MT 管理端本地功能页（侧栏「机构管理」），含**机构管理**、**机构用户管理**两个二级菜单及机构授权管理详情页；后端可预留规划该模块与 V8 应用集成管理中心标准页面的集成切换能力。

#### 6.2.1 功能描述

侧栏「机构管理」下二级菜单：**机构管理**、**机构用户管理**。

- 机构管理：以 KPI 卡（机构总数/已开通数（运行中）/已到期数/已关闭数/已禁用数）\+ 列表管理已开通机构，支持按统计单元、关键字、所属销售、授权版本、授权状态筛选，可「快捷开通新机构」；点击机构名称进入机构授权管理详情（应用授权/应用使用情况/操作日志）。
- 机构用户管理：按机构管理机构人员账号，支持角色与关键字筛选、启用/停用状态查看。

#### 6.3.4 业务规则

1. 停用后按该方案的新接入请求拒收；已入库数据保留（确认文案见上）。

2. 仅停用态可删除；删除不可恢复。

3. 至少勾选一个字段方可进入后续步骤/保存。

4. 开启白名单管控时，接入校验使用启用态 IP（见 6\.6 / 6\.10）。

5. 方案名称全局唯一；不符合字符规则时提示「仅支持汉字、英文字母、数字、英文连字符"-"」。

6. 接口地址全局唯一（系统网关\+自定义路由组合），据此关联区分接入数据来源供数方。

7. AppKey 鉴权凭证以「鉴权 Header」列表维护：参数值默认系统生成 32 位字母数字组合，可手动修改；详情页首个启用且参数名 AppKey 的行取值同步 appKey。

3. 消息队列订阅/消息队列推送通道新建（选项停用置灰，历史方案只读展示）。

2. 消息队列接入/推送通道恢复开放。

3. 「接收方管理」菜单开放与第三方接收方主路径启用。

4. 明细「平台」维度筛选与列恢复（基于内容平台字典）。

5. 真实调度引擎与对端联调、告警与 SLO 能力建设。

## 9. 验收要点

### 9.1 菜单与边界

- ☐ 侧栏含：综合看板、机构管理（机构管理/机构用户管理）、数据接入管理（接入方案管理/接入数据明细/字段库管理/IP白名单/供数方管理）、数据推送管理（推送方案管理/推送数据明细）、系统设置（数据字典）。

- ☐ **无**「接收方管理」菜单；访问 /push/receivers 重定向进入推送方案列表。

- ☐ 机构管理与机构用户管理为 MT 本地功能页（机构列表/授权管理/用户管理）；系统设置为本地数据字典页。

- ☐ 综合看板为单页总览，无总览/接入/推送一级 Tab。

### 9.2 综合看板

- ☐ 机构多选 \+ 今日/近3天/近1周/近1月筛选联动全部区块。

- ☐ 接入/推送概况 统计数据、趋势、分维、异常区可见。

- ☐ 下钻接入/推送明细时筛选项正确回填（含失败结果与 range 映射 today/d3/w1/m1）。

### 9.3 接入

- ☐ 表单接入方式仅 HTTP/HTTPS POST，「消息队列订阅」置灰停用；无文件类。

- ☐ 三步配置可保存并生成文档；预览/PDF 可用。

- ☐ 接口地址为「系统网关（只读）\+自定义路由」结构且全局唯一；接口响应码表格默认 5 行、不可新增。

- ☐ 鉴权方式默认 AppKey；鉴权 Header 列表自动填充首行（参数名 AppKey、32 位参数值），提示文案正确。

- ☐ 停用/删除确认文案正确；开启不可删。

- ☐ 列表接入数据量为累计/今日两列，均可下钻明细；列表筛选含方案/机构/供数方/状态。

- ☐ 明细默认无时间=全量；带参预填；无平台筛选与列。

### 9.4 推送

- ☐ 目标机构仅 MT；表单说明「推送目标仅支持 MT 机构」。

- ☐ 列表含**推送模式**筛选与列；成功量/失败量累计/今日共 4 列，下钻带 pushResult。

- ☐ 推送类型仅 HTTP/HTTPS POST（消息队列置灰）；无频次类筛选与列。

- ☐ 去重默认关、时间窗 1–168h 默认 72；预览 100 条文案正确。

- ☐ 明细含推送结果筛选与列；默认全量；抽屉不含供数方、时间字段为「推送时间」。

### 9.5 主数据与系统能力

- ☐ 字段引用不可删；模板系统内置不可删/不可编辑。

- ☐ 白名单启停提示正确；启用状态不可删除；供数方编码可复制。

- ☐ 机构列副信息「统计单元·销售」一致。

- ☐ 详情页无编辑（接入方案详情鉴权 Header 为唯一可编辑区，支持「保存鉴权 Header」独立保存）、无顶部 统计数据。

### 9.6 门户

- ☐ portal 可打开 MT 看板；外网/专网占位不阻断验收。

### 10.2 与历史文档差异裁定表

|**序号**|**差异点**|**历史口径（0920/V1.0）**|**现行口径（本版）**|**裁定说明**|
|---|---|---|---|---|
|1|机构管理/系统设置|复用 V8，菜单预留、页面暂不开发|MT 本地功能页（机构列表/授权管理/用户管理/数据字典）|按当前原型实现验收；V8 对接移入后续规划|
|2|AppKey 长度|8 位（AppSecret 16 位）|32 位字母数字组合，无独立 AppSecret|鉴权统一收敛为「鉴权 Header」键值对列表|
|3|鉴权 Header|单字段占位 X-App-Key|列表表格（启用/参数名/参数值/说明），选择 AppKey 且为空时自动填充首行|接入/推送两端口径一致；详情页可独立保存|
|4|接口地址|单字段整条 URL|系统网关（只读）\+自定义路由（可编辑）组合，全局唯一|路由格式与唯一性提交校验|
|5|成功响应码|单字段成功响应码|接口响应码表格，默认 5 行（200/400/401/403/500），行内编辑/删除，不可新增|结构化维护|
|6|去重时间窗|1–8760h 默认 72|1–168h 默认 72|按一周（7×24）上限收敛|
|7|量级列|接入量单列\+时间跨度切换；成功/失败单列|接入累计/今日两列；推送成功/失败累计/今日共 4 列|点击列值直接下钻明细|
|8|明细平台维度|保留平台筛选与列|移除（内容平台字典保留维护）|本期不开放，见 8.1|
|9|推送频次/批量上限|实时/Cron/固定间隔\+批量上限 1–100000|移除配置；增量默认实时、全量按系统默认调度执行|表单精简|
|10|消息队列|可选通道|停用新建（置灰），历史方案只读|本期不做，见 8.1|
|11|操作记录|最高 10 行滚动|分页每页 8 条|统一分页基线|
|12|方案删除后进入详情|弹窗「数据已被删除，5s后自动返回」|空态「未找到该方案」\+「返回列表」按钮|手动返回，无倒计时|

## 功能清单（精简 · 确认用）

| 模块 | 子模块 | 功能 | 功能描述 | 优先级 |
|------|--------|------|----------|--------|
| MT 运营端 | 供数方管理 | 主数据 | 供数方维护：维护供数方名称、编码、启停；被机构引用后不可删除仅可停用 | P0 |
| MT 运营端 | 供数方管理 | 凭证 | appkey 管理：一供数方一 appkey，支持查看/发放/轮换；仅用于接口推送鉴权与来源识别 | P0 |
| MT 运营端 | 供数统计 | 多维核验 | 按机构/接入方案/供数方多选与时间跨度查看接入量、堆积量及分维趋势；空选为全部 | P0 |
| MT 运营端 | 机构供数配置 | 关系配置 | 为机构单选接入方案与供数方（均必填），可填备注；决定计入与选用范围 | P0 |
| MT 运营端 | 机构供数配置 | 标准绑定 | （收敛）接入方案即配置单元；机构侧绑定/选用生效方案参与判定 | P0 |
| MT 运营端 | 字段库管理 | 全部字段 | 字段维护：列表筛选、编辑、启停、删除（有引用不可删） | P0 |
| MT 运营端 | 字段库管理 | 批量新增 | 独立表格页一次新增 1～N 条；字段名批内/库内判重 | P0 |
| MT 运营端 | 字段库管理 | 快速模板 | 模板管理：系统内置/用户自定义，供接入方案快速套用 | P0 |
| MT 运营端 | 数据接入管理 | 接入方案 | 三步配置基础信息、字段映射、接入方式；支持全局/机构、复制新增、同名校验、文档预览/PDF | P0 |
| MT 运营端 | 数据接入管理 | 接入方案 | 白名单开关与 HTTP 鉴权凭证（AppKey+AppSecret） | P0 |
| MT 运营端 | 数据接入管理 | IP 白名单 | 白名单维护：新增顺序为 IP→供数方→备注；方案开启管控时参与校验 | P0 |
| MT 运营端 | 数据推送管理 | 推送管理（预留深化） | 使用方/外推相关能力按规划预留，本期不以实装为验收项 | P2 |
| V8 机构端 | 数据概览 | 概览看板 | 展示已配置供数方数、入库总量、最近入库时间等（保持既有） | P0 |
| V8 机构端 | 供数统计 | 按供数方统计 | 按供数方核验入库条数及时间范围（保持既有） | P0 |
| V8 机构端 | 供数方查看 | 只读名单 | 只读查看本机构已配置供数方及状态（保持既有） | P0 |
| V8 机构端 | 接入规范 | 生效标准 | 预览与下载：预览/下载本机构生效标准（字段块+接入方式），转交供数方 | P0 |
| 系统能力 | 推送接收 | 接口路径 | appkey 鉴权入库：凭 appkey 识别厂商；校验通过后落库副本并打标（厂商/时间/机构） | P0 |
| 系统能力 | 推送接收 | 库表路径 | 供数方编码识别入库：凭行内供数方编码识别厂商；须含归属机构标识；落库打标同接口路径 | P0 |
| 系统能力 | 推送接收 | 安全校验 | 条件拒收：appkey 无效、IP 未命中、无法归属机构等情形拒收且不落库 | P0 |
| 后期规划 | 平台自有供数 | 平台自有供数 | 不区分机构的自有供数通道 | P2 |
| 后期规划 | 数据外推实装 | 数据外推实装 | 外推任务与配置界面实装（分析统计深化同步后置） | P2 |

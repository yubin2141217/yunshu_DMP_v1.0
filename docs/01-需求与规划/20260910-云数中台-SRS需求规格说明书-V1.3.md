### 3.5.2A MT 供数统计（相对 V1.0 增补 · 运营端）

**（一）功能需求概述**

平台运营按机构、接入方案、供数方及时间跨度查看接入量与堆积量，用于核验供数是否到达及堆积情况。

**（二）功能设计**

**筛选**

| 字段 | 控件 | 说明 |
|------|------|------|
| 机构 | 多选下拉 | 空选表示全部；占位文案「全部」 |
| 接入方案 | 多选下拉 | 空选表示全部；占位文案「全部」 |
| 供数方 | 多选下拉 | 空选表示全部；占位文案「全部」 |
| 时间跨度 | 单选 | 今日 / 近1天 / 近1周 / 近1月；默认「今日」 |

筛选项控件**固定宽度与高度**；多选标签不得因选中数量导致控件高度变化或错位。提供查询、重置。

**展示**

- KPI：接入总量、当前堆积  
- 聚合趋势图（接入量 / 堆积量）  
- 分维图：按机构、按接入方案、按供数方  
- 组合明细表：机构 × 方案 × 供数方  

**业务规则**

- 未选择某一维时按「全部」参与统计。无单独提示。  
- 筛选摘要区展示当前生效条件。  

**边界与异常**

- **无数据**：图表与表格按空态展示，不报错阻断

### 3.5.6A 机构供数配置（相对 V1.0 修订）

**（一）功能需求概述**

平台运营为机构配置可选用的接入方案与供数方，并填写备注。

**（二）功能设计**

| 字段 | 说明 |
|------|------|
| 机构 | 选择目标机构 |
| 接入方案 | **单选、必填** |
| 供数方 | **单选、必填**（文案为「供数方」，非「可接收供数方」多选） |
| 备注 | 可选；列表可展示 |

**业务规则**

- 未配置完整的机构，其入库计入与生效判定按既有规则执行。无单独提示。

### 3.5.7 元数据字段库（数据标准管理）【V1.3 全文替换】

**（一）功能需求概述**

平台运营维护可复用数据标准字段，作为接入方案字段映射的素材。

**（二）功能设计**

**列表与维护**

| 字段 | 说明 |
|------|------|
| 字段名 | 英文字段标识（字母/数字/下划线，以字母或下划线开头） |
| 描述 | 业务含义说明 |
| 数据类型 | 如 String / Int |
| 长度 | 可选，数字 |
| 缺省值 | 可选 |
| 业务分类 | 运维管理 / 文章 / 作者 / 平台 / 标注 / 其它 |
| 备注 | 可选 |
| 状态 | 启用 / 停用 |
| 引用方案数量 | 被多少接入方案引用；>0 时不可删除 |

支持筛选、详情、编辑（弹窗，字段名只读）、启用/停用、删除。

**页头**：不展示冗长产品说明文案。

**批量新增（独立页）**

- 入口：列表「新增字段」。  
- 表格样式：一行一条字段；可添加多行后一次提交。  
- 必填：字段名、描述、数据类型。  
- **判重**：本批内字段名不得重复；不得与已有字段名重复。冲突时提示并阻断提交。  

**平台预置与强约束字段（汇聚识别）**

| 字段名 | 必填口径 | 说明 |
|--------|----------|------|
| supplier_code | 库表路径必填；接口路径建议与凭证交叉校验 | 对应供数方编码 |
| org_id | 本期必填口径 | 归属机构标识 |

**业务规则**

- 停用后不可被新方案勾选；已被引用的历史方案展示不受影响。无单独提示。  
- 字段库不绑定某一供数方。无单独提示。  

**边界与异常**

- **空列表**：提示暂无字段，请先新增  
- **同名冲突**：提示字段名已存在或本批重复

### 3.5.8 接入方案管理【V1.3 全文替换】

**（一）功能需求概述**

平台运营维护接入方案：配置基础信息、字段映射与接入方式，发布后供机构选用，并生成接入文档。

**（二）功能设计**

**列表**

展示方案名称、范围、机构、字段摘要、接入方式、是否白名单、状态、发布时间。  
操作：详情、预览文档、编辑、**复制新增**、开启/停用、删除。

**复制新增**

进入新增流程并回填原方案配置；提交前须保证方案名称与已有方案不重复，否则提示并阻断。

**创建 / 编辑（三步）**

**步骤 1 · 基础信息**

| 字段 | 说明 |
|------|------|
| 方案名称 | 必填；汉字、英文字母、数字、下划线；最长 100；同名校验 |
| 状态 | 开关：开启 / 停用 |
| 范围 | 全局 / 机构。提示：**全局：所有机构都可选用本方案，机构：仅部分机构可选用本方案** |
| 机构 | 范围=机构时必选 |
| IP 白名单管控 | 开关；开启后推送须命中白名单 |
| 备注 | 可选，文本区域加高 |

**步骤 2 · 字段库配置**

- 从字段库勾选字段，并配置供数方侧字段名/类型映射。  
- 提示：从字段库选择要接入的数据，并可配置映射；不满足需求时联系管理员扩充。  
- 配置区宽度与步骤条对齐。  

**步骤 3 · 接入方式**

| 接入方式 | 本期 |
|----------|------|
| HTTP/HTTPS POST 推送 | 可用 |
| 消息队列订阅 | 可用 |
| 文件传输类 | **禁用**（不可新建） |

HTTP 关键配置：接口地址、协议、方法、鉴权（无鉴权 / AppKey+AppSecret）、请求头、最大 QPS、重试次数、重试间隔、成功响应码、数据编码、是否字段校验等。  
输入框提供格式类占位提示（如数字示例）。鉴权为 AppKey+AppSecret 时维护方案级凭证（可自动生成）。

**生成示例**

- 点击前校验接入基础信息必填项；缺失则报错并阻断。  
- 报文示例值按字段名、数据类型与业务含义自动填充贴近真实的样例。  

**方案预览 / 下载 PDF**

按当前配置生成文档，章节包括：概要、安全说明、接口或队列/文件信息、请求体字段、请求示例、响应约定。  
**不包含**独立「来源识别说明」章节。预览与 PDF 内容一致。

**连通性测试**

按当前接入方式探测连通性；失败时提示，是否允许保存以实现为准（演示可允许保存）。

**业务规则**

- 接入方案不绑定唯一供数方。无单独提示。  
- 开启白名单管控时，推送须通过 IP 白名单；白名单不单独作为厂商归属依据。无单独提示。  
- 全局范围启用互斥、机构范围启用互斥规则保持既有「同范围仅一份启用」口径（若实现有差异以实现与验收用例对齐）。  

**边界与异常**

- **同名**：提示方案名称已存在，不允许添加同名接入方案  
- **生成示例缺必填**：提示完善基础信息必填项  
- **无勾选字段**：不可完成提交

## 四、验收要点（V1.3 增补）

1. 字段批量新增：同名（批内/库内）均被拦截。  
2. 接入方案复制新增：回填完整；同名拦截。  
3. 生成示例：缺必填拦截；示例值非纯类型占位符。  
4. 预览与 PDF：与表单配置字段一致，无第 7 章来源识别说明。  
5. 供数统计：空选显示「全部」；控件高度不因多选抖动。  
6. 机构供数：方案与供数方单选必填；备注可保存展示。  
7. 文件传输类不可新建。

# 云数中台-接入方案管理列表优化设计方案

## 一、项目概述

### 1.1 背景

接入方案管理是运营日常配置与排障的主入口。现网列表以「名称 / 机构 / 供数方 / 接入方式 / 状态标签 / 时间」为主，缺少方案系统编号、接入量洞察与全局运营总览；状态启停依赖操作列文案按钮，信息密度与操作效率不足。

### 1.2 目标

在不大改新建/编辑流程的前提下，优化**接入方案列表页**，使运营可快速：

- 用方案 ID / 名称定位方案；
- 按时间跨度查看接入量并下钻样例数据；
- 在列表内直接启停（停用二次确认）；
- 通过顶部统计卡片掌握方案、机构、供数方及「活跃」规模。

### 1.3 设计原则

采用「清单需求 + 轻量运营增强」（方案二）：克制增量，优先扫读与排障效率；不做趋势分析台。

### 1.4 已确认口径

| 项 | 结论 |
|----|------|
| 活跃定义 | 近 1 周累计**接入**数据量 > 10,000 条 |
| 时间跨度 | 累计 / 今日 / 近 3 天 / 近 1 周 / 近 1 月 |
| 统计卡片 | 全局总览，不随筛选变化 |
| 状态开关 | 启用立即生效；停用二次确认 |
| 方案 ID | 后台自增数字（如 10086），不可手填 |
| 接入量弹窗 | 轻量：时间跨度 + 总条数 + 样例表 |
| 启用冲突 | 「同机构 + 同供数方」仅一条启用：冲突时**阻止并提示** |

## 二、功能范围

### 2.1 本期范围（接入方案列表页）

| 模块 | 内容 | 优先级 |
|------|------|--------|
| 统计区 | 方案总数（启用/总数）、机构数、供数方数、活跃方案/机构/供数方 | 核心 |
| 筛选 | 供数方下拉；方案名称模糊匹配名称+ID；保留机构/接入方式/状态 | 核心 |
| 列表字段 | 方案ID、名称+备注副行、机构+统计单元·销售副行、供数方、接入方式、接入数据量、状态开关、最近接入时间、创建/更新时间、操作 | 核心 |
| 接入量 | 列头切换时间跨度；点击打开轻量弹窗（跨度+总条数+样例） | 核心 |
| 状态 | Switch；启用立即生效；停用确认；去掉操作列「停用」 | 核心 |
| 增强 | ID 一键复制；时间跨度会话记忆；副信息省略+hover；开关失败回滚 | 重要 |

### 2.2 不在本期

趋势图、异常告警、统计卡片跟随筛选、多跨度并列表格、新建/编辑表单大改。

## 三、核心模块设计

### 3.1 页面结构

自上而下：标题区 → 统计卡片区 → 筛选 + 表格卡片 → 接入量轻量弹窗。

### 3.2 统计卡片

全局计算，不随筛选变化。卡片：方案总数（启用/总数）、机构数量、供数方数量、活跃方案、活跃机构、活跃供数方。旁注：「活跃 = 近 1 周累计接入 > 10,000 条」。样式对齐推送方案页 KPI 行。

### 3.3 筛选

- 方案名称：占位「搜索方案名称 / ID」，模糊匹配 `name` 与数字方案 ID。
- 供数方：下拉（启用中的供数方）。
- 保留：机构、接入方式、状态、查询、重置。

### 3.4 列表交互

- **方案 ID**：自增数字；点击复制。
- **方案名称**：主名称 + 副备注。
- **机构**：主机构名 + 副「统计单元·销售」。
- **接入数据量**：列头 Segmented/下拉切换跨度（会话记忆）；单元格「N 条」可点。
- **最近接入时间**：增强列，便于排障。
- **状态**：Switch；开=立即启用（冲突则失败回滚并提示）；关=确认后停用。
- **操作**：详情、预览文档、编辑、复制新增、删除；无启停按钮。

### 3.5 接入量弹窗

标题含方案名与 ID；时间跨度与列头一致并可切换；展示总条数；样例表最近 20 条（可翻页，上限约 100）；列取方案字段库；无数据空态。

## 四、数据结构与流向

### 4.1 关键字段

| 实体 | 字段 | 说明 |
|------|------|------|
| Standard | schemeNo | 自增数字方案 ID（展示与搜索） |
| Standard | remark | 名称副信息 |
| Standard | accessStats | 各时间跨度接入条数 |
| Standard | lastAccessAt | 最近接入时间 |
| Org | statUnit / salesName | 机构副信息「统计单元·销售」 |

### 4.2 时间跨度

`total` / `today` / `d3` / `w1` / `m1`，列表列头与弹窗共用；前端会话记忆当前跨度。

### 4.3 数据流

1. 进入列表 → 拉全局 KPI + 分页列表（含当前跨度下的接入量）。  
2. 切换跨度 → 刷新列表量字段（可本地映射，不必整表重查）。  
3. 点接入量 → 弹窗拉汇总条数 + 样例页。  
4. 点开关 → 启用直调 / 停用确认后调；失败回滚开关。

## 五、边界情况处理

| 场景 | 处理 |
|------|------|
| 无备注 / 无统计单元或销售 | 副行显示「—」 |
| 接入量为 0 | 显示 `0 条`，可点开空态弹窗 |
| 启用冲突（同机构+同供数方已有启用） | 阻止启用，Toast 提示，开关回滚 |
| 停用 | 二次确认后执行 |
| 启用失败（字段/接入配置不完整） | Toast 错误，开关回滚 |
| 副信息过长 | 单行省略，hover 展示全文 |
| 方案 ID 复制 | Toast「已复制」 |

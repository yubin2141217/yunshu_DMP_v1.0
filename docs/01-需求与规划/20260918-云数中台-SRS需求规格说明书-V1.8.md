## 二、项目概述

### 2.3 建设范围（相对 V1.7 调整）【V1.8 更新】

**本期新增 / 调整**

- **全局列表规范**：所有列表页筛选项前增加字段名标签；移除筛选区与结果表之间的「筛选结果数量条」，数量统计由分页组件 `show-total` 承载；数据明细页保留筛选标签行。
- **接入方式（HTTP）**：接口地址拆为「网关（只读）+ 路由（可编辑）」，路由自动生成、完整地址全局唯一强校验；鉴权方式仅「无鉴权 / AppKey」，选 AppKey 展示「鉴权 Header」列表；「接口响应码」为固定默认示例表格（行内可编辑、可删除、不可新增）；删除请求协议、重试、成功响应码、数据编码、字段校验开关等低频字段；「消息队列订阅」选项禁用置灰。
- **推送方案**：步骤 2 新增「选择推送字段」映射区与「刷新」；「预览数据」移至该区下方并展示映射后字段；去重时间窗上限 168h；步骤 3「消息队列推送」禁用、鉴权方式收敛为「无鉴权 / AppKey」、删除频次类型与批量上限等字段、「全量」模式显示「选择时间段」；推送示例按钮改为「保存配置并生成示例」。
- **列表列调整**：接入方案列表删除「接入方式」列、「接入数据量」拆为「累计 / 今日」两列；推送方案列表「成功量 / 失败量」拆为「累计 / 今日」四列，删除「推送方式」「频次类型」筛选项与列及时间跨度下拉。
- **明细页**：接入与推送数据明细删除「平台」筛选项与列；新增「内容标题」「URL 链接」文本筛选（模糊匹配）；列表新增「URL 链接」列，点击新窗口打开。
- **综合看板**：接入 / 推送统计卡片标题下增加口径说明文案；维度统计柱状图与列表默认展示 8 条；接入异常 / 推送异常各 Tab 增加分类提示说明并明确排序；异常字段名统一为「堆积量」「失败率」；异常区右上角统计数字统一样式。
- **字段库配置入口**：接入方案编辑与快速模板编辑页隐藏「Json 批量导入」按钮（组件能力保留，不在页面入口暴露）。
- **全局设计规范**：除机构管理与系统设置外的全部模块按《康奈网络MT系统产品规范》完成设计层对齐——顶栏（logo 点击回主页、右上角返回首页/消息/下载中心、点头像下拉退出登录并展示部门）、分页默认 100 条/页（10/50/100/200/500，翻页滚回表格顶部）、数字列居中、状态标签语义色、可点击字段 hover 下划线+手型、截断列 Tooltip、单位入表头、操作列固定右侧且次要/危险操作收进「...」更多菜单、成功提示「对象+结果」。详见 3.7。**仅设计规范层调整，功能与字段不变。**
- **接入方案详情页凭证**：鉴权方式为 AppKey 时，详情页凭证区由原「单独 AppKey 字段（自动生成按钮）」改为**鉴权 Header 可编辑表格**，与编辑页/推送页交互一致（增删行、行内编辑、启停、独立保存）。

### 3.5 功能详细设计

#### 3.5.1 综合看板【V1.8 更新】

**页面路径：** `/stats`
**优先级：** 高

页头右侧：机构多选（可搜索、可清空）、时间跨度（今日 / 近3天 / 近1周 / 近1月）、刷新。

页面结构（自上而下）：

1. **接入概况**：接入量、积压等主指标；机构数、方案数、供数方数、字段数等辅指标。可点击的指标进入接入数据明细并带上当前筛选。
2. **推送概况**：成功量、失败量、成功率、积压等。可点击的指标进入推送数据明细。
3. **数据接入 vs 推送趋势**：同一时间跨度与机构筛选下的接入量与推送成功量对比。
4. **接入统计**：按机构 / 按方案 / 按供数方切换；图表 + 表格；可下钻接入明细或接入方案。
   - 标题下说明文案：**按机构/方案/供数方维度查看历史全量数据接入情况**。
   - 柱状图与列表默认各展示 **8 条**。
   - 机构 / 供数方维度行含「方案数」列：按该范围内实际产生接入量的方案去重统计，**有接入量则方案数必 ≥ 1**。
5. **推送统计**：按机构 / 按方案切换；可下钻推送明细。
   - 标题下说明文案：**按机构/方案维度查看历史全量数据推送情况**。
   - 柱状图与列表默认各展示 **8 条**。
6. **值班提示（异常区）**：接入异常与推送异常两组卡片，各 Tab 分类名称下展示提示说明；右上角统计数字为红色文字胶囊「N 项」，两组样式统一。

**接入异常 Tab 口径**

| Tab | 定义（提示说明文案） | 列表字段与排序 |
|-----|----------------------|----------------|
| 零接入 | 近 3 天无数据接入的方案 | 按最近「接入时间」排序 |
| 高堆积 | 当前接入堆积数据量超过 100 条的方案 | 「堆积量」字段，按堆积量从大到小排序 |

**推送异常 Tab 口径**

| Tab | 定义（提示说明文案） | 列表字段与排序 |
|-----|----------------------|----------------|
| 高失败率 | 近 3 天推送总失败率超过 10% 的方案 | 「失败率」字段，按失败率从大到小排序 |
| 高堆积 | 当前推送堆积数据量超过 100 条的方案 | 「堆积量」字段，按堆积量从大到小排序 |

> 字段名相对 V1.7 校正：接入高堆积「堆积」→「堆积量」；推送高失败率「数量」→「失败率」、高堆积「数量」→「堆积量」。

#### 3.5.3 数据接入管理【V1.8 更新】

**接入方案列表**

- KPI：方案总数（开启/停用可点选筛选）、机构数量、供数方数量、活跃相关指标。
- 筛选：方案、机构、供数方、状态。**无「接入方式」筛选项**。
- 列：方案 ID、方案名称（主名 + 备注）、机构（主名 + 统计单元·所属销售）、供数方、**接入数据量（累计）、接入数据量（今日）**、最近接入、状态、操作。**无「接入方式」列**。
- 接入数据量两列均可点击进入接入数据明细：累计列携带全量时间窗，今日列携带 `today` 时间窗。
- 操作：详情、编辑、复制、启停、文档相关操作。
- 同机构 + 同供数方同时仅允许一份开启方案。

**接入方案配置（分步填写，共 3 步）**

1. **基础信息**：方案名称、机构、供数方、状态等。方案与所选供数方一对一绑定。
2. **字段库配置**：勾选字段并可配置供数方字段映射；可选用快速模板。**「Json 批量导入」按钮隐藏**（不在页面入口暴露；组件能力保留）。
3. **接入方式**：
   - 接入方式下拉仅「HTTP/HTTPS POST 推送」可选；**「消息队列订阅」选项禁用置灰**（文件类不出现在选项中）。
   - HTTP 分支字段见下。

**HTTP 分支字段规格**

| 分区 | 字段 | 规格 |
|------|------|------|
| 基础信息 | 接口地址 | **网关（只读）+ 路由（可编辑）** 拼接。网关为系统配置（`https://ingress.yunshu.example.com`）；路由为空进入本步时自动生成 `/api/v1/push/` + 8 位随机字母数字；格式校验以 `/` 开头，仅允许字母/数字/`-`/`_`/`/`。完整地址**全局唯一**：路由失焦即时校验、提交强校验，重复报错「接口地址已存在，请修改路由部分」。字段下方常驻提示 |
| 基础信息 | 请求方法 | 固定 POST |
| 基础信息 | 鉴权方式 | 仅「无鉴权」/「AppKey」 |
| 基础信息 | 鉴权 Header | 仅选 AppKey 时展示。列表字段：启用复选框 / 参数名 / 参数值 / 说明 / 删除，底部「添加鉴权 Header」按钮。**默认第一行**：参数名 `AppKey` + 系统生成 32 位字母数字值；提示「AppKey系统默认生成32位字母数字组合，可手动修改」 |
| 流量 & 限流配置 | 最大 QPS 上限 | 1–10000 |
| 接口响应码 | 响应码表格 | **固定默认示例 5 条**：200 成功 / 400 请求参数错误 / 401 鉴权失败 / 403 禁止访问 / 500 服务端错误；支持行内编辑与删除，**不支持新增行**；列表两列为「响应码」「说明」，操作列含删除 |

**相对 V1.7 删除的字段**：请求协议（协议由系统网关 HTTPS 前缀决定）、重试次数、重试间隔、成功响应码（单字段，由接口响应码表格替代）、数据编码、开启字段校验、鉴权 Header 名（并入鉴权 Header 列表）、AppSecret（凭证精简为仅 AppKey）。

**方案凭证（鉴权 Header）**：鉴权方式为 AppKey 时，凭证统一由「鉴权 Header」列表承载（不再有单独的 AppKey 输入字段）。AppKey 值长度 32 位（大小写字母 + 数字，系统生成可手动修改）。**详情页**凭证区为可编辑鉴权 Header 表格（启用复选框 / 参数名 / 参数值 / 说明 / 删除 + 「添加鉴权 Header」按钮），支持行内增删改与启停，通过「保存鉴权 Header」按钮独立保存；保存时校验至少保留一个启用且参数名非空的行；首个启用且参数名为 `AppKey` 的行同步写入 `appKey` 字段（兼容历史凭证逻辑）。

**接入方案详情**

- 无「编辑」按钮、无顶部统计卡片。
- 结构：基础信息 → 字段范围 → 接入方式。接入方式区块与编辑页字段对齐（网关 + 路由、鉴权 Header、接口响应码表格等）。
- **例外：鉴权 Header 表格在详情页可编辑**（增删行 / 行内编辑 / 启停 / 「保存鉴权 Header」独立保存），为页面唯一可编辑区，替代原单独 AppKey 凭证卡。
- 含「操作记录」审计卡片。

**接入数据明细**

- 筛选：方案、机构、供数方、**内容标题、URL 链接**（文本模糊匹配）、接入时间、发布时间。时间默认空表示历史全量；仅从看板等入口携带时间时预填。**无「平台」筛选项**。
- 列：方案名称、机构、供数方、接入时间、内容标题、**URL 链接**（`<a target="_blank">` 新窗口打开，无值显示「—」）、发布时间、作者昵称。
- 行点击打开数据详情面板：含方案、方案 ID、机构、机构补充、供数方、接入时间及动态字段。

| 项 | 规格 |
|----|------|
| KPI | 方案总数（开启/停用可点选）、机构数量、累计成功推送、推送成功率（无流量显示「—」） |

**推送方案配置（分步填写，共 3 步）**

1. **基础信息**：方案名称、机构、状态；接收方相关信息在本步维护。名称规则见 V1.7 3.5.7。
2. **选择推送数据**【V1.8 更新】
   - 来源类型：接入方案，或数据源。
   - 选接入方案：搜索选择接入方案。选数据源：数据源 ID 与数据源名称分两列；名称在 ID **失焦后**自动填入：纯数字 ID 填入「示例数据源」；非纯数字填入「未查询到相关数据源，请更改数据源ID」；清空 ID 同时清空名称。
   - **选择推送字段**（新增区域，位于「接入方案」或「数据源 ID」字段下方）：以字段选择器实现**云数中台字段 ↔ 接收方字段**的关联映射（分组标题「云数中台字段 / 接收方字段」，参考接入方案字段库配置交互）。标签行右侧含**「刷新」按钮**：重新拉取字段列表，**未选择数据来源时禁用**。
   - **字段列表仅在选择接入方案或输入数据源 ID 后展示**；默认空态提示「请选择接入方案或输入数据源ID」。
   - **预览数据**按钮位于「选择推送字段」区域下方；点击展示**映射后的字段名及数据，最多前 100 条**，并提示当前来源全量范围条数。
   - 数据过滤：满足全部/任一条件才推送；不添加则不过滤。
   - 「数据去重」默认关闭；开启后「时间窗」**最大值 168（小时）**，提示「时间窗最大 168h（即 7×24 小时，一周）」；至少选一个去重字段。
3. **推送方式**【V1.8 更新】
   - **推送方式**：仅「HTTP/HTTPS POST 推送」可选；**「消息队列推送」选项禁用置灰**（MQ 分支仅历史方案详情回显，回显时顶部提示「消息队列推送当前已停止新建」）。
   - HTTP 分支字段：
     - 基础信息：推送接口地址、请求方法（固定 POST）、鉴权方式。
     - **鉴权方式**：仅「无鉴权」/「AppKey」（历史 token 方案详情回显为禁用项「Token（历史方案）」）。
     - **鉴权 Header**：仅选 AppKey 时展示；列表结构同接入（启用 / 参数名 / 参数值 / 说明 / 删除 + 添加按钮）；**默认第一行**：参数名 `AppKey` + 系统生成 32 位字母数字值，提示「AppKey系统默认生成32位字母数字组合，可手动修改」。
     - **重试配置**：重试次数（0–10）、重试间隔 ms（0–60000）。
   - **推送模式**：增量 / 全量；**选「全量」时显示「选择时间段」字段**（日期范围选择）。
   - **相对 V1.7 删除的字段**：请求协议、Content-Type、最大 QPS 上限、成功响应码、频次类型（实时/Cron/固定间隔）、间隔（分钟）、批量上限、「数据配置」模块。
   - **推送示例**：按钮文案为**「保存配置并生成示例」**，位于示例文本框上方独立行；点击先保存配置并校验（HTTP：接口地址 / 请求方法 / 鉴权；MQ：NameServer/Brokers、Topic），缺失必填项时提示后再生成；占位文案「点击「保存配置并生成示例」生成内容」。

**推送方案详情**

- 无「编辑」、无顶部统计卡片。
- 结构：基础信息 → 数据来源（含选择推送字段与映射）→ 推送方式。与编辑页字段对齐。
- 含「操作记录」审计卡片。

## 五、验收要点【V1.8 更新】

- 接入方案列表：无「接入方式」列；接入数据量为「累计 / 今日」两列且均可下钻。

- 推送方案列表：成功量 / 失败量为累计 / 今日四列；无「推送方式」「频次类型」筛选与列；无时间跨度下拉。
- 推送方案编辑：步骤 2 有「选择推送字段」映射区与「刷新」按钮（未选来源禁用）；字段列表未选来源时为空态；「预览数据」位于映射区下方且展示映射后字段（≤100 条）；时间窗 > 168 不可输入；步骤 3「消息队列推送」置灰；鉴权方式仅无鉴权 / AppKey；选「全量」出现「选择时间段」；示例按钮为「保存配置并生成示例」且位于文本框上方。

- 其余验收要点继承 V1.7 第五章。

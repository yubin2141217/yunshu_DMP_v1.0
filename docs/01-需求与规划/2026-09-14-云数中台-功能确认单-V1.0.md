## 功能确认表

| 模块 | 子模块 | 功能 | 功能描述 | 优先级 |
|------|--------|------|----------|--------|
| MT管理端 | 综合看板 | 接入概况 | 云数中台数据接入整体情况汇总统计，包括接入数据总量、接入方案数、当前堆积量，以及机构、供数方和已接入字段数量等 | P0 |
| MT管理端 | 综合看板 | 推送概况 | 云数中台数据推送整体情况汇总统计，包括推送成功量、失败量、成功率，以及推送方案数、覆盖机构与待推积压等 | P0 |
| MT管理端 | 综合看板 | 接入与推送趋势 | 按所选时间跨度展示数据接入量与推送成功量的对比趋势，支撑值班与汇报快速看势 | P0 |
| MT管理端 | 综合看板 | 分维统计与下钻 | 接入侧按机构/方案/供数方、推送侧按机构/方案展示柱状图与列表；支持点击柱图下钻至明细页并携带筛选条件 | P0 |
| MT管理端 | 综合看板 | 全局筛选 | 支持按机构多选与时间跨度（今日/近3天/近1周/近1月）过滤看板全部统计与图表 | P0 |
| MT管理端 | 接入方案管理 | 方案列表与看板 | 方案列表展示方案 ID、名称、机构、供数方、接入方式、分时接入量、状态等；顶部 KPI 支持按状态快速筛选 | P0 |
| MT管理端 | 接入方案管理 | 方案配置 | 支持新增/编辑/复制接入方案，完成基础信息、字段库映射与接入方式（HTTP/消息队列）配置 | P0 |
| MT管理端 | 接入方案管理 | 启停管控 | 列表开关启停方案；停用需确认，停用后按该方案接入的数据中台将拒绝接收，已接入数据不受影响 | P0 |
| MT管理端 | 接入方案管理 | 删除管控 | 支持删除停用态方案；开启态不可删（按钮置灰并提示）；删除后不可恢复 | P0 |
| MT管理端 | 接入方案管理 | 接入文档 | 支持接入接口文档预览与 PDF 下载，便于同步给供数方 | P0 |
| MT管理端 | 接入方案管理 | 方案详情 | 只读查看方案完整配置；标题栏固定，支持复制新增返回编辑流 | P1 |
| MT管理端 | 接入数据明细 | 明细查询 | 按接入方案、机构、供数方与时间范围查询已接入明细，支持字段级模糊筛选与结果集分页查看 | P0 |
| MT管理端 | 字段库管理 | 字段维护 | 维护平台标准字段（新增/编辑/启停/删除），支撑接入方案字段拼装；被引用字段不可删除 | P0 |
| MT管理端 | 字段库管理 | 批量新增与模板 | 支持批量新增字段，以及快速模板（系统内置/自定义）供方案配置时套用 | P1 |
| MT管理端 | IP白名单 | 白名单维护 | 维护允许接入的来源 IP 及归属供数方；方案开启白名单管控后参与接入校验 | P0 |
| MT管理端 | 供数方管理 | 供数方主数据 | 维护供数方名称、编码与启停；被机构/方案引用后限制删除，保障主数据可控 | P0 |
| MT管理端 | 推送方案管理 | 方案列表与看板 | 方案列表展示方案 ID、名称、机构、数据范围、通道、模式、分时成功/失败量与状态；顶部 KPI 可快速筛选 | P0 |
| MT管理端 | 推送方案管理 | 方案配置 | 支持新增/编辑/复制推送方案，配置接收方、数据范围（接入方案/数据源）、过滤去重与推送通道（HTTP/消息队列）及调度策略 | P0 |
| MT管理端 | 推送方案管理 | 启停与删除 | 列表开关启停；停用后不再按该方案推送，已推送数据保留；仅停用态可删除且不可恢复 | P0 |
| MT管理端 | 推送方案管理 | 方案详情 | 只读查看推送方案完整配置；标题栏固定，支持复制新增 | P1 |
| MT管理端 | 推送数据明细 | 明细查询 | 按推送方案、机构、推送结果与时间范围查询已推送明细，支持字段筛选与分页查看 | P0 |
| MT管理端 | 接收方管理 | 第三方接收方 | 维护非 MT 的第三方推送接收方机构档案（编码、关联 MT 机构、联系人等），供推送方案选用 | P0 |
| MT管理端 | 公共能力 | 机构展示规范 | 列表/看板中机构统一展示主名称及统计单元、销售等副信息，便于运营识别归属 | P1 |
| 系统能力 | 数据接入 | 安全接入校验 | 按方案配置完成鉴权、IP 白名单等校验；不通过则拒收且不落库 | P0 |
| 系统能力 | 数据接入 | 落库打标 | 校验通过后落库并打标来源厂商、机构、接入时间等，支撑后续统计与追溯 | P0 |
| 系统能力 | 数据推送 | 主动推送执行 | 按推送方案调度，经 HTTP 或消息队列向接收方推送，并记录成功/失败与积压 | P0 |

## 本期边界（确认）

1. 本确认单聚焦 **MT 管理端**运营能力与配套接入/推送执行能力。  
2. V8 机构端既有能力若需单独确认，另附机构端确认单。  
3. 平台自有供数、更复杂外推编排等后续规划项不纳入本期签字范围。

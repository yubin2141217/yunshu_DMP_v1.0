## 二、项目概述

### 2.3 建设范围（相对 V1.6 调整）

**本期新增 / 调整**

- **系统设置**（运营端一级菜单）：当前二级页仅 **数据字典**。  
- **数据字典**：维护「字段业务分类」「内容平台」「字段数据类型」三类码表；开启项供字段库与明细筛选选用。  
- **综合看板**：单页总览（接入概况 + 推送概况 + 趋势 + 分类统计 + 值班提示），**不再**拆成「总览 / 接入 / 推送」三个独立页签作为入口。  
- **数据推送管理**侧栏仅两项：推送方案管理、推送数据明细。**接收方管理不作为独立菜单**（原路径进入后转到推送方案列表；接收方在推送方案配置中维护）。  
- 推送列表与配置用语统一为 **推送方式**、**推送模式**、**频次类型**（实时 / Cron / 固定间隔）。  
- 接入方案、推送方案名称规则统一。  
- 字段库：状态切换、勾选后批量编辑 / 批量停用 / 批量删除；开启态不可删除。  
- 业务分类、字段数据类型、内容平台下拉均取数据字典中 **开启** 项。

**本期不做（延续）**

- 文件类接入方式与文件类推送方式正式开放。  
- 跨机构外推、真实调度引擎、看板环比/同比、延迟分位与 SLO、告警规则引擎。  
- 系统设置下其它子页（账号权限、参数中心等）本期不交付。  
- JDBC 接入配置中的「模式 / Schema」保持原含义，**不得**改名为「推送模式」。

### 2.4 术语（补充 / 校正）

| 统一用语 | 含义 |
|----------|------|
| 系统设置 | 运营端一级菜单，承载平台级码表等配置 |
| 数据字典 | 可维护的码表集合；本期三类：字段业务分类、内容平台、字段数据类型 |
| 推送方式 | 中台主动外推的通道类型。选项：HTTP/HTTPS POST 推送、消息队列推送 |
| 推送模式 | 增量 / 全量 |
| 频次类型 | 实时、Cron、固定间隔。列表与筛选展示这三项中文，不拼表达式 |
| 数据来源 | 推送方案取数范围：接入方案，或外部数据源（数据源 ID + 名称） |
| 开启 / 停用 | 列表与表单状态文案（不用「启用」） |

## 三、功能需求

### 3.1 功能菜单（当前真源）

**运营端（MT）**

侧栏顺序固定如下。

1. **综合看板**（一级，无子菜单）  
2. **机构管理**  
   - 机构管理  
   - 机构用户管理  
3. **数据接入管理**  
   - 接入方案管理  
   - 接入数据明细  
   - 字段库管理  
   - IP 白名单  
   - 供数方管理  
4. **数据推送管理**  
   - 推送方案管理  
   - 推送数据明细  
5. **系统设置**  
   - 数据字典  

不出现在侧栏、但路由仍注册的页面：接入方案（旧页）、字段/模板/方案的新增编辑详情、机构授权详情。  
不出现在侧栏、进入后转到其它页：数据查询 → 接入数据明细；机构供数配置 → 接入方案管理；接收方管理 → 推送方案管理；机构推送任务 → 推送方案管理。

**机构端（V8）**

登录后顶栏：数据概览、供数统计、供数方查看、接入规范。

### 3.5 功能详细设计

#### 3.5.1 综合看板

**页面路径：** `/stats`  
**优先级：** 高

页头右侧：机构多选（可搜索、可清空）、时间跨度（今日 / 近3天 / 近1周 / 近1月）、刷新。

页面结构（自上而下）：

1. **接入概况**：接入量、积压等主指标；机构数、方案数、供数方数、字段数等辅指标。可点击的指标进入接入数据明细并带上当前筛选。  
2. **推送概况**：成功量、失败量、成功率、积压等。可点击的指标进入推送数据明细。  
3. **数据接入 vs 推送趋势**：同一时间跨度与机构筛选下的接入量与推送成功量对比。  
4. **接入统计**：按机构 / 按方案 / 按供数方切换；图表 + 表格；可下钻接入明细或接入方案。  
5. **推送统计**：按机构 / 按方案切换；可下钻推送明细。  
6. **值班提示**：零接入、高堆积、高失败率等列表（有数据才作为关注项展示）。

相对 V1.5：取消「总览 / 接入 / 推送」三页签入口；值班区与分类统计放在同一页下半区。

#### 3.5.2 机构管理

**机构列表 `/org/open`**

- 页头说明：查看已开通机构的授权状态、到期日与所属销售，可快捷开通。  
- KPI 卡片可点击筛选。  
- 筛选：统计单元、关键字（机构名称 / 全称 / 统一社会信用代码）、所属销售、授权版本、状态。  
- 操作含「管理」，进入授权详情。

**机构授权详情 `/org/open/:id`**

- 展示机构主名、机构 ID、授权版本与状态、到期信息。  
- 三个页签：**应用授权**、**应用使用情况**、**操作日志**。  
- 无「编辑」入口改基础档案（快捷开通在列表完成）。

**机构用户 `/org/users`**

- 可切换当前机构。  
- KPI：已激活已开通、未开通等人数。  
- 维护本机构人员开通状态与组织角色。

#### 3.5.3 数据接入管理（相对既有版本的落地口径）

**接入方案列表**

- KPI：方案总数（开启/停用可点选筛选）、机构数量、供数方数量、活跃相关指标。  
- 筛选：方案、机构、供数方、接入方式、状态。接入方式仅「HTTP/HTTPS POST 推送」「消息队列订阅」，无文件类。  
- 列：方案 ID、方案名称（主名 + 备注）、机构（主名 + 统计单元·所属销售）、供数方、接入方式、接入数据量、最近接入、状态、操作。  
- 可筛选列点击后填入对应筛选并查询。  
- 接入数据量进入接入数据明细，携带方案。  
- 操作：详情、编辑、复制、启停、文档相关操作；文案为「复制」。  
- 同机构 + 同供数方同时仅允许一份开启方案；冲突时提示先停用已有方案。

**接入方案配置（分步填写，共 3 步）**

1. 基础信息：方案名称、机构、供数方、状态等。方案与所选供数方一对一绑定。  
2. 字段库配置：勾选字段并可配置供数方字段映射；可选用快速模板。  
3. 接入方式：HTTP 或消息队列（无文件类）。

方案名称规则见 3.5.7。名称不可与其它接入方案重复。

**接入方案详情**

- 无「编辑」按钮、无顶部统计卡片。  
- 结构：基础信息 → 字段范围 → 接入方式。

**接入数据明细**

- 筛选：方案、机构、供数方、平台、时间。时间默认空表示历史全量；仅从看板等入口携带时间时预填。  
- 平台选项来自数据字典「内容平台」的开启项。  
- 行点击打开数据详情面板：含方案、方案 ID、机构、机构补充、供数方、接入时间及动态字段。

**字段库** 见 3.5.6。  
**IP 白名单 / 供数方**：归属数据接入管理；供数方开启态不可删除（须先停用）；白名单按供数方添加 IP。

#### 3.5.4 数据推送管理（校正 V1.6）

相对 V1.6 的文档校正：

| V1.6 写法 | 本期真源 |
|-----------|----------|
| 二级页含接收方管理 | 侧栏不含接收方；接收方在方案「基础信息」中维护 |
| 筛选项「通道类型」、列「通道 / 模式」 | 「推送方式」「推送模式」 |
| 列表无频次列 | 有「频次类型」筛选与列：实时 / Cron / 固定间隔 |
| 「推送类型」 | 对外统一称「推送方式」 |

**推送方案列表 `/push/schemes`**

| 项 | 规格 |
|----|------|
| KPI | 方案总数（开启/停用可点选）、机构数量、累计成功推送、推送成功率（无流量显示「—」） |
| 筛选 | 方案、机构、推送方式、推送模式、频次类型、状态；无供数方筛选 |
| 列 | 方案 ID、方案名称、机构（主名 + 统计单元·所属销售）、数据来源、推送方式、推送模式、频次类型、成功量、失败量、状态、操作 |
| 数据来源 | 两行：第一行主名称；第二行来源类型。接入方案时第二行为「接入方案」；外部数据源时第二行为「数据源 · {ID}」 |
| 频次类型 | 仅展示「实时」「Cron」「固定间隔」，与筛选项文案一致 |
| 点击填入筛选 | 方案名称 / 机构 / 推送方式 / 推送模式 / 频次类型 / 状态 |
| 成功量 / 失败量 | 进入推送数据明细，携带方案 + 推送结果 |
| 操作 | 详情、编辑、复制、启停；文案为「复制」 |

**推送方案配置（分步填写，共 3 步）**

1. **基础信息**：方案名称、机构、状态；接收方相关信息在本步维护。名称规则见 3.5.7。复制进入时提示修改方案名称后提交。  
2. **选择推送数据**  
   - 来源类型：接入方案，或数据源。  
   - 选接入方案：搜索选择接入方案，可预览数据。  
   - 选数据源：数据源 ID 与数据源名称分两列。数据源名称只读，根据 ID **在输入框失焦后** 自动填入：纯数字 ID 填入「示例数据源」；非纯数字填入「未查询到相关数据源，请更改数据源ID」（样式按未命中提示）；清空 ID 时同时清空名称。输入过程中不即时改名称。  
   - 预览提示：预览最多 100 条样例；展示当前来源全量范围条数。  
   - 数据过滤：满足全部/任一条件才推送；不添加则不过滤。  
   - 「数据去重」默认关闭。  
3. **推送方式**：推送方式（HTTP/HTTPS POST 推送、消息队列推送，说明为中台主动推送，当前这两种）；推送模式增量/全量；频次类型（增量时可选实时；Cron 须填至少 5 段表达式；固定间隔单位为分钟）。

**推送方案详情**

- 无「编辑」、无顶部统计卡片。  
- 结构：基础信息 → 数据来源 → 推送方式。推送方式区块展示推送方式、推送模式、频次类型；Cron 时另展示表达式。

**推送数据明细 `/push/push-data`**

- 筛选：推送方案、机构、平台、推送结果（成功/失败）、推送时间。时间默认空=全量。  
- 平台选项来自数据字典「内容平台」开启项。  
- 列表在推送时间后有「推送结果」列（成功/失败）。  
- 行打开数据详情面板：**不展示供数方**；展示方案名称、方案 ID、机构、机构补充、推送时间及动态字段（含推送结果文案）。

#### 3.5.5 系统设置 · 数据字典

**页面路径：** `/dict`  
**菜单位置：** 系统设置 → 数据字典  
**优先级：** 高

**页面目的：** 维护三类码表，供字段库与明细筛选引用。停用后 **新配置不可选**；已落库数据仍按原码展示。

**字典类型（页签）**

| 类型名称 | 用途 |
|----------|------|
| 字段业务分类 | 字段库业务分类筛选与填写 |
| 内容平台 | 接入数据明细、推送数据明细的「平台」筛选 |
| 字段数据类型 | 字段库及字段映射中的数据类型 |

预置项（不可删除；编码不可改）至少包括：

- 字段业务分类：运维管理、文章、作者、平台、标注、其它  
- 内容平台：微博、微信公众号、今日头条、抖音、网站  
- 字段数据类型：String、Int  

**列表**

- 筛选：名称 / 编码关键字、状态（开启/停用）。  
- 列：编码、名称、排序、状态、更新时间、操作。  
- 状态：列表内切换开启/停用。  
- 操作：编辑；删除规则如下。

**删除规则**

- 预置项：删除不可用，悬停提示「预置字典项不可删除」。  
- 非预置且开启：删除不可用，悬停提示「开启状态的字典项不可删除，请先停用」。  
- 非预置且停用：可删除，弹出确认后删除。

**新增 / 编辑**

| 字段 | 约束 |
|------|------|
| 字典类型 | 必填；编辑时不可改 |
| 编码 | 必填，最长 32；同一类型下唯一；预置项编码不可改 |
| 名称 | 必填，最长 50 |
| 排序 | 必填，0～9999，列表按排序展示 |
| 状态 | 开启后可被配置页下拉选用 |

#### 3.5.6 字段库管理

**页面路径：** `/metadata`  
**页签：** 全部字段 / 快速模板

**全部字段**

- 筛选：字段名/描述、业务分类（字典开启项）、状态。  
- 勾选后出现：批量编辑、批量停用、批量删除。  
- 开启状态的字段不可删除（单条与批量相同），悬停提示请先停用。  
- 列表状态可切换开启/停用；停用后不可被 **新** 接入方案勾选。  
- 新增字段、批量编辑中的业务分类与数据类型选项来自数据字典开启项。

**快速模板**

- 系统内置模板不可删除；用户自定义模板可新增/编辑（含供数方字段映射）。  
- 接入方案「字段库配置」可下拉选用或保存为模板。

**字段详情 / 模板详情：** 无「编辑」按钮（编辑从列表进入）。

#### 3.5.7 方案名称（公共规则）

适用于 **接入方案** 与 **推送方案** 的名称：

- 允许：汉字、英文字母、数字、英文连字符 `-`。  
- 不允许空格及其它标点。  
- 长度不超过 100。  
- 提示文案与校验失败文案须与上列规则一致（连字符表述为英文连字符“-”，不要写成下划线）。

#### 3.5.8 机构端（V8）

保持既有能力：登录；数据概览；供数统计；供数方查看；接入规范（预览并下载本机构生效标准）。本期菜单与路径无增减。

## 四、数据口径（增量）

| 数据 | 用途 |
|------|------|
| 字典项 status=开启 | 字段库分类/类型、明细平台下拉 |
| 字典项停用 | 新配置不可选；历史值仍展示原名称 |
| 推送方案频次类型 | 列表/筛选/详情文案：实时、Cron、固定间隔 |
| 数据源 ID（纯数字 / 非纯数字） | 失焦后名称分别为「示例数据源」与未查询到提示 |
| 推送明细详情 | 不含供数方字段 |
| 接入明细详情 | 含供数方 |
| 机构 statUnit / salesName | 含机构列的列表副信息 |

## 五、验收要点

- 侧栏末项为「系统设置」，其下仅「数据字典」；数据接入管理下 **没有** 数据字典。  
- 数据字典三类页签、预置不可删、开启不可删、停用后字段库/平台筛选不再出现该项。  
- 推送方案列表列名与筛选项为推送方式、推送模式、频次类型；频次三种中文与筛选一致。  
- 数据来源两行展示；数据源名称仅在 ID 失焦后填入。  
- 方案名称拒收下划线、空格等非法字符，接受「省局-HTTP」。  
- 推送数据详情无供数方；接入数据详情有供数方。  
- 字段库勾选后可批量编辑/停用/删除；开启态删除按钮不可用。  
- 综合看板为单页，右上角机构 + 时间跨度可用。  
- 任意详情页无「编辑」、无顶部统计卡片（与 V1.6 一致）。  
- 机构端四项菜单仍可进入。

本版按运营端、机构端 **已注册路由** 反向同步，作为后续研发真源。V1.6 中「接收方管理为二级页」「推送列表无频次列」「通道/模式」等表述以本版为准废止。综合看板以单页双流总览为准，不再要求三页签独立入口。系统设置本期只交付数据字典，其它设置类子页不在范围。

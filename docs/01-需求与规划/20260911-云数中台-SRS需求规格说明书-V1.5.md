### 3.5.2A 综合看板（替换原「MT 供数统计」边界说明）

**（一）功能需求概述**

平台运营在综合看板查看接入与推送的整体吞吐、成功率、积压与异常提示，并可下钻至明细或方案。

**（二）功能设计**

**公共筛选**

| 项 | 规则 |
|----|------|
| 时间跨度 | 今日/近3天/近1周/近1月/累计等（与现网一致） |
| 机构 | 多选；空=全部；过滤推送侧按方案 orgId |
| 操作 | 查询、重置、刷新 |

**Tab「总览」**

| 区域 | 内容 |
|------|------|
| 汇报 KPI | 接入总量、推送成功量、推送成功率、接入方案数、推送方案数、待推积压 |
| 链路对照 | 同公共时间窗：接入总量 vs 推送成功量 |
| 失败 TopN | 按推送方案失败量排序 |
| 积压 TopN | 按推送方案 backlog 排序 |
| 近 24h 失败趋势 | **固定近 24 小时**，独立于汇报时间跨度 |
| 接入异常提示 | 启用且近 1 日接入量为 0 的接入方案 |

**Tab「接入」**

- 专属筛选：接入方案、供数方  
- KPI：接入总量、当前堆积、覆盖机构、供数方数  
- 趋势 + 按机构/接入方案/供数方分维 + 组合明细表（规格继承 V1.3）

**Tab「推送」**

- 专属筛选：推送方案  
- KPI：成功量、失败量、成功率、积压、启用方案数  
- 成功/失败趋势；按机构、按推送方案（可选通道类型）；方案明细表  

**下钻**

- 接入总量 → 接入数据明细（带时间、机构）  
- 推送成功/失败相关 → 推送数据明细或推送方案列表  
- TopN / 明细行 → 对应方案详情  

**（三）验收要点**

1. 三 Tab 可切换；公共筛选在切换后仍保留。  
2. 总览 KPI 同时反映接入与推送；无流量成功率显示「—」。  
3. 值班近 24h 趋势不随汇报时间跨度改写。  
4. 失败/积压 TopN 与零接入提示可跳转。  
5. 接入 Tab 行为不低于 V1.3 供数统计验收项。

## 五、非功能与约束（增量）

- 不下钻到单条 URL/正文级列表（高基数）；明细复用既有明细页。  
- 总览聚合接口宜一次返回 KPI+TopN+趋势点，避免瀑布请求。

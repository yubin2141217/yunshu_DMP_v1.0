# 云数中台 V8 机构端 · 前端开发任务清单

> 依据 [V8 机构端设计方案 v1.0](./2026-09-20-云数中台V8机构端-设计方案-v1.0.md) 第 6.2 节"已实现前端调整方向"拆解。
> 本期为**前端原型**，数据均走本地 Mock；真实微信认证、集成中心权限字典、监控/推送后端接口后续替换适配层即可，页面不变。
> 估算单位：人天（前端，含自测，不含 UI 设计与后端联调）。负责人、迭代周期待排期补充。

## 三、关键依赖与风险

| 项 | 说明 | 应对 |
| --- | --- | --- |
| 微信扫码认证 | 原型点击二维码即可，真实认证依赖公司认证服务 | 用 A03 适配层隔离，页面先行，后续只换适配层 |
| 集成中心权限点字典 | 菜单点 + 供方候选需集成中心下发 | C05 用 mock 模拟接口形态，字段对齐后无缝替换 |
| 监控阈值基准 | 断供 N 小时、涨跌/拒收率阈值由 MT 定 | 前端只读展示规则，不提供编辑入口 |
| 正文合规 | content 不得下发/渲染 | 类型层（C01）即剔除 content，F01/F02 专项核查外链与无正文 |
| 样式隔离 | 新增页面需继续限定在 v8.scss 作用域 | B05 统一收口，构建后回归 MT 端样式 |
| 拒收/推送数据 | 拒收不落库、推送为 MT 记录 | 仅做聚合统计与只读明细，不建设条目级拒收数据 |

## 四、建议交付顺序（里程碑）

1. **M1 地基**：A01–A03、C01–C03、B01–B04 —— 扫码可进、权限可隔离、菜单与数据通路打通。
2. **M2 P0 主链路**：D01、D02、D05、E01–E07、E10–E11 —— 概览/统计/规范 + 入库核对外链 + 监控告警消息闭环 + 用户权限。
3. **M3 验收**：F01–F03 —— P0 全量权限与边界走查、构建与双向跳转回归。
4. **M4 P1 增强**：A04、B05、C04–C05、D03–D04、D06、E08–E09、E12、F04 —— 拒收统计/导出、推送回流、机构授权、个人设置等。

## 二、建设范围（相对 V1.5 调整）

### 2.1 本期新增 / 调整

**数据推送管理（方案即运行单元）**

- 一级菜单下二级页：**推送方案管理**、**推送数据明细**、**接收方管理**。  
- **不再**将「机构推送任务」作为独立运行/统计主页面；推送方案自身承载启停、调度与方案级 stats。  
- 推送类型（通道）选项仅：`HTTP/HTTPS POST 推送`、`消息队列推送`；**筛选项与表单均不出现文件类**。  
- 说明文案：中台主动推送的方式，当前支持 HTTP 接口和消息队列两种方式。

**推送方案列表**

| 项 | 规格 |
|----|------|
| KPI | 方案总数（含启用/停用细分，可点击筛状态）、机构数量、累计成功推送、推送成功率 |
| 筛选 | 方案、机构、通道类型、推送模式、状态；**无供数方筛选项** |
| 列 | 方案名称、机构（主名+「统计单元·所属销售」）、数据范围、通道、模式、成功量、失败量、状态、操作；**无频次列、无最近推送列** |
| 点击回填 | 方案名称 / 机构 / 通道 / 模式 / 状态点击后填入对应筛选并刷新 |
| 成功量/失败量 | 跳转推送数据明细，携带方案 + 推送结果（成功/失败） |
| 操作 | 详情、编辑、复制、启停；文案为「复制」（非「复制新增」） |

**推送方案配置（选择推送数据）**

- 预览提示：预览最多展示 100 条样例数据，所选数据来源目前全量范围数据 N 条，可预览查看并设置数据过滤范围。  
- 「数据去重」开关**默认关闭**。

**推送数据明细**

- 筛选：方案、**推送结果**（成功/失败）、时间范围。  
- 列表在「推送时间」后增加「推送结果」列，展示「成功」「失败」。  
- 时间筛选**默认空**，查询历史全量；仅当从综合看板等入口携带 `range` / `dateFrom`+`dateTo` 时预填。

**接入方案管理**

- 「接入方式」筛选项仅：`HTTP/HTTPS POST 推送`、`消息队列订阅`；**无文件传输类**。  
- 列表操作「复制」（原「复制新增」）。  
- 机构列展示「统计单元·所属销售」副信息（与其它含机构列的列表一致）。

**接入数据明细**

- 时间筛选默认空，历史全量；仅带参入口预填时间。

**详情页（全局）**

- 详情页**不提供「编辑」按钮**（编辑从列表进入）。  
- 详情页**不展示顶部统计 KPI 卡片**。  
- 接入方案详情与推送方案详情：结构对齐为「基础信息 → 范围/字段 → 方式配置」，描述列表 `bordered` + `size=large`。

**机构展示**

- Mock/演示机构名采用接近真实命名（如陕西省网信办、咸阳市网信办等）。  
- 凡列表出现「机构」列，主文案下展示：所属统计单元·所属销售。

### 2.2 本期不做（延续）

- 文件通道正式开放与生产联调；跨机构外推；真实调度引擎；看板环比/同比、延迟 SLO、告警规则引擎。

## 三、功能需求（增量）

### 3.1 推送方案管理

| ID | 需求 | 优先级 |
|----|------|--------|
| PS-L-01 | 列表 KPI 含方案总数（启用/停用 chip 可筛）、机构数、累计成功、成功率 | 高 |
| PS-L-02 | 可筛选字段支持单元格点击回填 | 高 |
| PS-L-03 | 成功量/失败量下钻推送明细并带方案+结果 | 高 |
| PS-L-04 | 通道类型选项与展示文案为 HTTP/HTTPS POST 推送、消息队列推送 | 高 |
| PS-C-01 | 数据去重默认关；预览提示按全量条数文案 | 中 |
| PS-D-01 | 详情无编辑、无统计卡；含基础信息/数据范围/推送方式 | 中 |

### 3.2 推送数据明细

| ID | 需求 | 优先级 |
|----|------|--------|
| PD-01 | 筛选项「推送结果」：成功/失败 | 高 |
| PD-02 | 列表列「推送结果」：成功/失败（位于推送时间后） | 高 |
| PD-03 | 时间默认空=全量；带参才预填 | 高 |

### 3.3 接入方案与接入明细

| ID | 需求 | 优先级 |
|----|------|--------|
| AS-01 | 接入方式筛选项不含文件类 | 高 |
| AS-02 | 操作「复制」；机构副信息 | 中 |
| AD-01 | 接入明细时间默认空=全量 | 高 |
| AD-02 | 详情无编辑、无统计卡 | 中 |

## 四、接口 / 数据口径（增量）

| 数据 | 用途 |
|------|------|
| 推送方案 `stats.successTotal` / `failTotal` | 列表成功/失败量、成功率、KPI |
| 推送明细 `push_status` ∈ {success, fail} | 推送结果筛选与列展示（UI 文案：成功/失败） |
| 机构 `statUnit` / `salesName` | 列表机构副信息 |
| 明细查询无 `dateFrom`/`dateTo` | `range=total`，按全量样例窗口生成/查询 |

---

## 五、验收要点（增量）

- 推送方案列表无供数方筛选、无频次/最近推送列；KPI 与点击回填可用。  
- 成功量进明细后自动筛该方案成功数据；失败量同理。  
- 推送类型下拉仅两项中文选项，无文件类；列表/筛选/详情文案一致。  
- 接入/推送明细无时间默认值时可见历史全量数据。  
- 任意详情页无「编辑」与顶部统计卡。

## 二、项目概述（变更摘录）

### 2.3 建设范围（相对 V1.3 调整）

**本期功能（相对 V1.3 新增 / 调整）**：

- **数据推送管理**：一级菜单下二级页「推送方案」「机构推送任务」  
- 推送方案：通道 HTTP/MQ（文件禁用）、结构化鉴权、Cron/间隔、批量上限、增量/全量  
- 机构推送任务：挂推送方案；数据范围为该机构全部已入库；同机构同通道类型唯一（启停均占坑）；列表运行态与简易 KPI  
- **MT 供数统计**：保持 V1.3 能力；规划更名为「数据概览」，后续扩展外推整体分析（本期推送模块不建复杂看板）  
- 保持：V1.3 字段库、接入方案、机构供数、白名单、汇聚落库、V8 下载等  

**本期不做 / 禁用**：

- 文件传输类接入方式与外推通道正式开放（下拉保留但禁用）  
- 跨机构外推 / 独立使用方主数据  
- 任务级按接入方案或字段子集裁剪  
- 真实调度引擎与对端生产联调（原型以可配置 + Mock 运行态验收）  
- 「数据概览」外推图表完整实现（仅定边界）  
- 不区分机构自有供数实装  

### 2.4 术语（补充）

| 统一用语 | 含义 |
|----------|------|
| 推送方案 | MT 侧外推配置模板：通道、鉴权、频次、批量、增量/全量；不绑定接入方案 |
| 机构推送任务 | 将推送方案挂接到机构并启停的执行配置；数据范围为该机构全部已入库数据 |
| 通道类型 | 外推通道分类：HTTP、消息队列、文件（文件本期禁用） |
| 数据概览 | 「供数统计」规划更名后的模块名；承接接入与外推整体统计分析 |

### 3.5.13 数据推送管理 · 推送方案（新增）

**（一）功能需求概述**

平台运营维护可复用的外推方案模板，定义通道、鉴权、推送模式与频次策略，供机构推送任务挂接。

**（二）功能设计**

**列表**

| 展示项 | 说明 |
|--------|------|
| 方案名称 | 全局唯一 |
| 通道类型 | HTTP / 消息队列 / 文件 |
| 推送模式 | 增量 / 全量 |
| 频次摘要 | Cron 或固定间隔描述 |
| 状态 | 启用 / 停用 |
| 更新时间 | — |
| 操作 | 详情、编辑、启停；可选复制新增 |

**表单 · 基础信息**

| 字段 | 必填 | 说明 |
|------|------|------|
| 方案名称 | 是 | 全局唯一 |
| 状态 | 是 | 启用 / 停用 |
| 备注 | 否 | — |

**表单 · 推送通道**

| 通道类型 | 本期 |
|----------|------|
| HTTP | 可用；配置对端地址、协议、方法、鉴权与必要请求头等（语义对齐接入 HTTP，方向为中台外呼） |
| 消息队列 | 可用；配置连接与 Topic/Queue 及鉴权等（对齐接入 MQ） |
| 文件传输类 | **禁用**（选项可见不可选） |

**表单 · 推送策略**

| 字段 | 必填 | 说明 |
|------|------|------|
| 推送模式 | 是 | 增量 / 全量，用户自选 |
| 频次类型 | 是 | Cron 表达式 / 固定间隔（分钟） |
| Cron 或间隔值 | 是 | 与频次类型对应；非法则不可保存 |
| 批量条数上限 | 是 | 正整数 |
| 失败重试 | 否 | 可与通道区合并展示 |

**（三）业务规则**

1. 仅状态为启用的方案可被新机构推送任务选用。  
2. 方案停用后，不允许新任务选用；已挂接且仍为启用的任务不得保持启用（须提示运维停用任务）。  
3. 修改方案通道类型时，须校验是否导致任一机构出现「同通道类型多任务」冲突；冲突则不可保存。  
4. 推送方案不绑定接入方案，不维护字段勾选。  

**（四）边界与异常**

| 场景 | 系统行为 |
|------|----------|
| 方案名称重复 | 提示不可保存 |
| Cron / 间隔非法 | 提示并阻断保存 |
| 批量上限为空或 ≤0 | 提示并阻断保存 |
| 选择文件通道 | 不可选、不可提交 |
| 通道类型变更导致机构冲突 | 提示冲突任务并阻断 |

### 3.5.14 数据推送管理 · 机构推送任务（新增）

**（一）功能需求概述**

平台运营将推送方案挂接到机构并启停；系统按方案策略，将该机构全部已入库数据外推至本机构接收端。

**（二）功能设计**

**列表上方简易汇总**

| 指标 | 说明 |
|------|------|
| 任务总数 | 当前任务条数 |
| 启用中 | 状态为启用的任务数 |
| 近 24h 失败 | 近 24 小时内运行失败的任务数（演示可以模拟数据） |

**列表**

| 展示项 | 说明 |
|--------|------|
| 机构 | 目标机构 |
| 推送方案 | 方案名称 |
| 通道类型 | 取自方案 |
| 任务状态 | 启用 / 停用 |
| 最近运行状态 | 成功 / 失败 / 运行中 / 未运行 等 |
| 成功次数 / 失败次数 | 累计或约定窗口，实现阶段统一一种口径 |
| 最近失败原因 | 摘要 |
| 更新时间 | — |
| 操作 | 编辑、启停 |

**新建 / 编辑**

| 字段 | 必填 | 说明 |
|------|------|------|
| 机构 | 是 | 单选 |
| 推送方案 | 是 | 仅可选启用中的方案；展示名称与通道类型 |
| 数据范围 | — | 只读说明：「推送该机构全部已入库数据」；无接入方案选择 |
| 任务状态 | 是 | 启用 / 停用 |

**（三）业务规则**

1. 数据来源仅为中台已入库数据；不从机构业务库 JDBC 拉取。  
2. 数据范围固定为所选机构的全部已入库数据；不按接入方案或字段子集裁剪。  
3. 唯一约束：同一机构 + 同一通道类型仅允许一条任务记录；**启用与停用均占坑**。  
4. 不得配置跨机构外推。  
5. 不提供独立「使用方」主数据；机构即为接收归属。  
6. 不提供独立「运行记录」三级页面；运行信息在任务列表展示。  

**（四）边界与异常**

| 场景 | 系统行为 |
|------|----------|
| 机构尚无入库数据 | 允许创建任务；运行结果可为成功且推送条数为 0 |
| 所选方案已停用 | 新建/编辑不可选该方案 |
| 同机构同通道类型已存在任务 | 保存拦截并提示已有任务（含停用记录） |
| 试图选择非本机构数据 | 无入口 |

## 四、验收要点（V1.4 增补）

在 V1.3 验收要点基础上增加：

1. 侧栏可进入「推送方案」「机构推送任务」两个二级页；原使用方/JDBC 源端外推交互不再作为验收对象。  
2. 推送方案：HTTP/MQ 可配置保存；文件通道不可新建；增量/全量、Cron/间隔、批量上限可保存；同名拦截。  
3. 机构推送任务：可挂启用方案；数据范围只读为机构全量入库；同机构同通道类型重复创建被拦截（含停用占坑）。  
4. 任务列表展示运行态与简易 KPI。  
5. 供数统计页本期不强制外推图表；外推整体分析归属后续「数据概览」。
